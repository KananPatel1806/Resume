# Kanan Patel | Professional Portfolio

## Overview
This is the personal portfolio of **Kanan Patel**, a Full-Stack Web Developer and AI/ML Specialist. It serves as a digital resume, showcasing professional experience, education, technical skills, and a curated list of featured projects.

The portfolio is a single-page application designed with a heavy emphasis on User Experience (UX) and Performance, using a dark/light mode glassmorphic UI and dynamic scrolling animations.

## Key Features
- **Dynamic Theme Toggling:** A custom Light/Dark mode switch that saves user preferences.
- **Interactive CLI Terminal:** A functional command-line interface (Ctrl+K) for recruiters to explore details.
- **In-Browser Resume Viewer:** A beautifully integrated modal that allows reading the PDF resume directly on the website.
- **Performance Animations:** Uses Typed.js for hero text animations, Particles.js for the background canvas, and VanillaTilt.js for 3D card hover effects.
- **Live Contact Form:** Fully functional contact form integrated with EmailJS.
- **Fully Responsive:** Built with Bootstrap 5 to ensure flawless scaling on mobile phones, tablets, and desktop monitors.

## Technology Stack
- **Structure & Styling:** HTML5, CSS3, Bootstrap 5.3
- **Logic & Interactivity:** JavaScript (ES6+)
- **Animation Libraries:** AOS.js, Typed.js, Particles.js, Vanilla-Tilt.js
- **Icons & Typography:** FontAwesome 6, Google Fonts (Inter, Space Grotesk)
- **External Integrations:** EmailJS
